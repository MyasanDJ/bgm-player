BGM Player v5.1 Playlist

プレイリスト方式に対応しました。
ジャケット維持・スプレッドシート小窓向けUI・スマホUIは現状ベースのままです。

音源の置き方:
track1.mp3
track2.mp3
track3.mp3

M4A/WAVでもOK:
track1.m4a
track2.wav
track3.mp3

曲ごとのジャケット:
cover1.png
cover2.png
cover3.png

共通ジャケット:
cover.png
cover.jpg
cover.jpeg

仕様:
- track1 → track2 → track3 の順で自動再生
- 初期状態は全曲ループ
- ループボタンで切り替え
  🔁 全曲ループ
  🔂 1曲ループ
  ➡️ ループなし
- ⏮ / ⏭ で前後の曲へ移動
- track1系が無い場合は従来通り bgm.mp3 / bgm.m4a / bgm.wav を1曲として読みます。

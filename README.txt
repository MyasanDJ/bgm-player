BGM Player v5.3 Playlist Stable

従来UIを維持したプレイリスト版です。

音源の置き方:
track1.mp3
track2.mp3
track3.mp3

M4A/WAVでもOK:
track1.m4a
track2.wav
track3.mp3

曲ごとのジャケット:
cover1.png
cover2.png
cover3.png

共通ジャケット:
cover.png / cover.jpg / cover.jpeg

仕様:
- 1曲が終わると次の曲へ進みます。
- 初期状態は全曲ループです。
- ⏮ / ⏭ で前後の曲へ移動できます。
- 🔁 全曲ループ / 🔂 1曲ループ / ➡️ ループなし を切り替えできます。
- track1系が無い場合は従来通り bgm.mp3 / bgm.m4a / bgm.wav を1曲として読みます。
